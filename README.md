# Manufacturing Operations Monitor

## Manufacturing 4.0 | Industrial Analytics | Process Improvement

A learning and engineering portfolio project focused on understanding manufacturing operations through data.

The project will gradually develop a monitoring system to explore production output, machine performance, downtime, product quality and operational efficiency using data analysis and software development.

## Project Objective

The objective is to build a manufacturing operations monitoring system that can help answer practical production questions:

- Are production lines meeting their targets?
- How much downtime is occurring?
- What are the main reasons for machine stoppages?
- How many products are being rejected?
- How can production performance be measured and improved?

## Planned Features

- Production performance monitoring
- Machine status tracking
- Downtime analysis
- Quality and defect monitoring
- Production KPIs
- Overall Equipment Effectiveness (OEE)
- Data visualisation
- Operational reporting

## Technology Stack

The technologies will be introduced as the project develops.

- Python
- Pandas
- SQL
- Data visualisation
- Streamlit (planned)

## Project Status

**Status: Initial setup**

This project is currently in its initial stage. The data, analysis, calculations and dashboard will be developed incrementally.

The initial version will use simulated manufacturing data. It is a learning and portfolio project and is not currently connected to real industrial equipment.

## Learning & Development

This project is being developed step by step to explore data analytics, manufacturing processes, software development and concepts related to Industry 4.0.
